# useTimeout

## Overview

`useTimeout` owns a one-shot timer, tracks whether it is pending, and keeps callback changes separate from timer restarts.

## Signature

```ts
function useTimeout(
  callback: () => void,
  delay: number | null,
): { readonly cancel: () => void; readonly pending: boolean };
```

## Parameters

`callback` is updated from the latest commit. `delay` is clamped to zero; `null` disables the timer.

## Returns

A stable `cancel` action and a `pending` flag.

## Behavior

Changing `delay` restarts the timer. Changing only `callback` does not. Completion and `cancel` set `pending` to false; unmount clears the timer.

## SSR / RSC

No timeout starts on the server. The initial `pending` value is `delay !== null`; client effects reconcile it.
