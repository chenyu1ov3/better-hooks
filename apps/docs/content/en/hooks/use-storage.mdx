# use-storage

## Overview

`better-hooks/use-storage` is the aggregate storage entry. It exports both browser-storage Hooks and their shared TypeScript contracts from the module that contains their common implementation. It does not export a separate `useStorage` Hook.

## Exports

```ts
export {
  useLocalStorage,
  useSessionStorage,
  type StorageOptions,
  type StorageState,
  type UseStorageResult,
} from 'better-hooks/use-storage';
```

Use the dedicated [useLocalStorage](/hooks/use-local-storage) and [useSessionStorage](/hooks/use-session-storage) entries when a module needs only one Hook. The aggregate entry is useful when both belong to the same feature.

## Behavior

Both exports call the shared internal storage factory with a different browser store. Importing the aggregate entry adds no wrapper and does not initialize browser storage at module load.

## SSR / RSC

The exported Hooks use the captured initial value for the server snapshot and access storage only when a browser is available. Call them in a Client Component.
