# Installation

## Install the package

Install the verified `0.2.0` release with pnpm:

```sh
pnpm add better-hooks
```

The same package is available through npm and other package managers. Review the [npm package page](https://www.npmjs.com/package/better-hooks) for release metadata.

## Runtime requirements

The package manifest currently declares:

| Requirement                        | Supported range    |
| ---------------------------------- | ------------------ |
| React                              | `>=19.0.0 <20.0.0` |
| Node.js for development and builds | `>=22.18.0`        |
| Module format                      | ESM only           |

React is a peer dependency. The package has no runtime dependency beyond the React APIs supplied by the consuming application.

## Import model

The package name is `better-hooks`. The root export is convenient, while every Hook also has an explicit direct entry such as `better-hooks/use-toggle`. Direct entries make the requested module graph clear and work with the package's `sideEffects: false` declaration.

## Release verification

The `0.2.0` release passed export checks, declaration generation, package validation, size budgets, and a clean documentation build. Follow the [Changelog](/changelog) for subsequent releases.
