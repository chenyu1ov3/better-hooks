# ADR 001 — Runtime boundaries

## Status

Accepted for the preview implementation.

## Context

React can render without committing. Server builds may also evaluate modules where browser globals do not exist. Work started during import or render can leak, duplicate, or make hydration depend on the host environment.

## Decision

Public entries have no import-time browser or React side effects. Render stays free of listener registration, timer creation, and network work. Browser subscriptions and asynchronous work start through effects or `useSyncExternalStore` subscriptions and provide symmetric cleanup.

## Consequences

Browser-facing values need explicit server snapshots. Hooks are Client Component APIs even though their modules are safe to include in server builds. Tests must cover unmount and Strict Mode replay, not only the happy path.
