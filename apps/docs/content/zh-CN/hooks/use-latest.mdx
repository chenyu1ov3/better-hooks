# useLatest

## 概览

`useLatest` 返回一个引用稳定的 ref，其 `current` 始终保存最近一次已提交的值。

## 函数签名

```ts
function useLatest<T>(value: T): React.RefObject<T>;
```

## 参数

`value` 可以是任意类型；值变化时，ref 本身的引用不会改变。

## 返回值

返回使用首次渲染值初始化且引用稳定的 `RefObject<T>`。

## 行为

ref 会在 Effect 中更新，而不是在渲染期间更新，因此长生命周期的外部回调不会观察到被放弃的并发渲染值。

## SSR / RSC

SSR 时 `current` 为本次渲染值，后续只会在客户端提交后更新。请仅在 Client Component 中调用。
