# useIsomorphicLayoutEffect

## 概览

`useIsomorphicLayoutEffect` 在 `window` 存在时使用 `useLayoutEffect`，在其他环境中使用 `useEffect`。

## 函数签名

```ts
const useIsomorphicLayoutEffect: typeof React.useEffect;
```

## 参数

接收与 React Effect API 相同的回调和依赖数组。

## 返回值

返回值与 React `useEffect` 的类型保持一致。

## 行为

模块加载时会根据环境选择实现：浏览器中在 Layout Effect 阶段运行；浏览器外采用普通 Effect 语义，避免服务端警告。

## SSR / RSC

服务端分支使用 `useEffect`，不会在服务端渲染期间执行。该 API 仍然是 Client Component Hook。
