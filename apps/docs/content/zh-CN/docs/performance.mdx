# 性能

## 已验证的包属性

当前源码提供独立 Hook 入口和聚合存储入口、显式 package exports，没有额外运行时依赖，只有一项 React peer dependency。包仅发布 ESM，并声明 `sideEffects: false`。

这些是可验证的包属性，并不表示每种打包工具或每个应用都会得到完全相同的输出结果。

## 只导入需要的行为

在 `0.2.0` 中，每个 Hook 都提供 `better-hooks/use-media-query` 这样的直接入口。直接导入可以让应用依赖图更明确；最终的生产体积仍取决于使用方的编译器、目标环境、压缩工具和周边代码。

## 共享订阅

在所有权和清理规则清晰的前提下，使用外部状态源的 Hook 会共享底层订阅。同一 `Window` 中相同的媒体查询会复用一个条目；联网状态在每个浏览器上下文中共用一对监听器；窗口尺寸则由当前订阅者共用一个 `resize` 监听器。

## 调度纪律

定时器和监听器只在组件提交后建立，并在依赖变化或组件卸载时清理。稳定的回调 ref 可以避免仅因函数引用变化就重建原生监听器。

## 测量原则

官网不会发布缺少依据的竞品对比或合成基准数据。只有数据来自当前构建，并明确标注入口、压缩方式与版本时，才会展示包体积数字。
