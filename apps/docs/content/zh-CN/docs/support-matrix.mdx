# 支持矩阵

## 运行时与工具

| 范围                   | 当前支持情况             |
| ---------------------- | ------------------------ |
| React                  | `>=19.0.0 <20.0.0`       |
| 包模块                 | 仅 ESM                   |
| TypeScript             | 从类型化源码生成声明文件 |
| 仓库任务使用的 Node.js | `>=22.12.0`              |
| 仓库包管理器           | pnpm                     |

## 渲染环境

| 环境                    | 支持边界                                       |
| ----------------------- | ---------------------------------------------- |
| 客户端渲染 React        | 支持                                           |
| SSR 与 hydration        | 通过明确的服务端快照支持                       |
| React Server Components | 导入安全，但 Hook 必须在 Client Component 调用 |
| Browser Worker          | 不是 React DOM 目标，不作支持声明              |
| React Native            | 尚未测试，不作支持声明                         |

## 浏览器 API

各 Hook 会先检测所需 API。`matchMedia` 不可用时，`useMediaQuery` 返回回退值；存储访问或序列化失败时，存储 Hook 会保留当前值并暴露错误；事件目标缺失时，事件 Hook 会跳过订阅。

## 框架

项目暂未发布框架兼容矩阵。只要框架支持 React 19、ESM 包，以及相应的 Client Component 或 hydration 边界，就具备使用这个包的基础。正式声明支持某个框架之前，需要先补充专门的集成测试。

## 更新原则

这份矩阵以当前 manifest 和实现为准。只有更广泛的能力已经通过测试或发布验证后，才会在这里补充相应声明。
