# 支持矩阵

拿不准某个环境能不能用时，先看这里。列出的都是当前版本实际测试并公开声明的范围，不会把一个本地示例扩大成对所有框架或浏览器的承诺。

## 包与运行时

| 范围       | 当前支持情况                                             |
| ---------- | -------------------------------------------------------- |
| React      | `>=19.0.0 <20.0.0`                                       |
| 模块       | 仅 ESM                                                   |
| TypeScript | 从类型化源码生成声明文件                                 |
| Node.js    | 工具链支持 `^22.18.0` 或 `>=24.11.0`；仓库固定 `24.20.0` |
| 运行时依赖 | 只有 React peer dependency                               |

## 渲染方式

| 环境                    | 支持边界                                  |
| ----------------------- | ----------------------------------------- |
| 客户端渲染 React        | 支持                                      |
| SSR 与 Hydration        | 通过明确的服务端快照支持                  |
| React Server Components | 导入安全；Hook 在 Client Component 中运行 |
| Browser Worker          | 不是 React DOM 目标，不作支持声明         |
| React Native            | 尚未测试，不作支持声明                    |

## 浏览器行为

Hook 会先检测自己需要的 API。`matchMedia` 缺失时，`useMediaQuery` 使用回退值；存储访问或序列化失败时，存储 Hook 保留当前值并暴露错误；事件目标不存在时，事件 Hook 跳过订阅；剪贴板访问被拒绝时，错误仍会交给调用方。

## 框架

框架需要支持 React 19、ESM，以及相应的客户端或 Hydration 模型。只有仓库中存在对应集成测试时，才会在这里点名声明支持。

## 什么时候更新这张表

只有 manifest、实现和测试一起前进，支持范围才会扩大。在那之前，上面的内容就是当前版本的公开边界。
