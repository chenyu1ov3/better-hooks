# 支持矩阵

## 运行时与包

| 范围       | 当前支持情况             |
| ---------- | ------------------------ |
| React      | `>=19.0.0 <20.0.0`       |
| 包模块     | 仅 ESM                   |
| TypeScript | 从类型化源码生成声明文件 |
| Node.js    | `>=22.18.0`              |

## 渲染边界

| 环境                    | 支持边界                                       |
| ----------------------- | ---------------------------------------------- |
| 客户端渲染 React        | 支持                                           |
| SSR 与 hydration        | 通过明确的服务端快照支持                       |
| React Server Components | 导入安全，但 Hook 必须在 Client Component 调用 |
| Browser Worker          | 不是 React DOM 目标，不作支持声明              |
| React Native            | 尚未测试，不作支持声明                         |

## 浏览器 API 行为

各 Hook 会先检测所需 API。`matchMedia` 不可用时，`useMediaQuery` 返回回退值；存储访问或序列化失败时，存储 Hook 会保留当前值并暴露错误；事件目标缺失时，事件 Hook 会跳过订阅。这些回退行为属于文档约定的运行时契约。

## 框架

框架兼容性取决于三个边界：React 19、ESM 包，以及相应的 Client Component 或 hydration 模型。对具体框架作出支持声明前，需要有专门的集成测试。

## 更新原则

这份矩阵以当前 manifest 和实现为准。只有更广泛的能力已经通过测试或发布验证后，才会在这里补充相应声明；某个本地示例通过，不代表对所有框架或浏览器版本作出承诺。
