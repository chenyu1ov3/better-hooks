# 安装

## 安装包

已验证的 `0.2.0` 版本可以通过 pnpm 安装：

```sh
pnpm add better-hook
```

也可以使用 npm 或其他包管理器；版本信息请查看 [npm 包页面](https://www.npmjs.com/package/better-hook)。

## 运行要求

当前 package manifest 声明：

| 要求                     | 支持范围           |
| ------------------------ | ------------------ |
| React                    | `>=19.0.0 <20.0.0` |
| 开发与构建使用的 Node.js | `>=22.18.0`        |
| 模块格式                 | 仅 ESM             |

React 是 peer dependency。除了由使用方应用提供的 React API，这个包没有其他运行时依赖。

## 导入方式

包名为 `better-hook`。根入口适合集中导入，每个 Hook 也有 `better-hook/use-toggle` 这样的显式直接入口。直接入口能更清楚地表达依赖关系，并配合包的 `sideEffects: false` 声明完成 Tree Shaking。
