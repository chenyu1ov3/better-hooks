# 安装

一个包，不需要额外配置。

## 添加依赖

```sh
pnpm add better-hooks
```

也可以使用 npm 或其他包管理器。已发布版本和元数据可以在 [npm 包页面](https://www.npmjs.com/package/better-hooks)查看。

## 选择导入方式

想让依赖一眼可见，可以使用独立入口：

```ts
import { useToggle } from 'better-hooks/use-toggle';
```

同一个模块里需要多个 Hook 时，也可以从根入口导入：

```ts
import { useDebounce, useToggle } from 'better-hooks';
```

两种方式都是带类型的 ESM 导入。包声明了 `sideEffects: false`；区别主要在代码表达是否清楚，以及构建工具最先看到哪一段模块图。

## 确认运行要求

| 要求                     | 支持范围                  |
| ------------------------ | ------------------------- |
| React                    | `>=19.0.0 <20.0.0`        |
| 开发与构建使用的 Node.js | `^22.18.0` 或 `>=24.11.0` |
| 模块格式                 | 仅 ESM                    |

仓库将开发、CI 与发布使用的 Node.js 固定为 `24.20.0`，同时保留 `22.18.0` 作为最低兼容基线。React 是 peer dependency，除此之外没有其他运行时依赖。
