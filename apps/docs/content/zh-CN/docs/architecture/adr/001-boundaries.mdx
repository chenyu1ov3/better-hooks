# ADR 001 — 运行时边界

## 状态

已被预览版实现采用。

## 背景

React 可能执行一次渲染，却最终不提交结果。服务端构建也可能在没有浏览器全局对象的环境中加载模块。如果在导入或渲染期间启动任务，就可能造成资源泄漏、重复执行，或让 hydration 结果依赖宿主环境。

## 决策

公开入口在导入时不会产生浏览器或 React 副作用。渲染期间不注册监听器、不创建定时器，也不启动网络任务。浏览器订阅与异步任务通过 Effect 或 `useSyncExternalStore` 订阅启动，并提供成对的清理逻辑。

## 影响

面向浏览器的值必须提供明确的服务端快照。即使模块可以安全进入服务端构建，Hook 仍属于 Client Component API。测试不仅要覆盖正常路径，还必须覆盖组件卸载与 Strict Mode 重放。
