# 介绍

Better Hooks 是一组处于预览阶段、小巧且类型安全的 React 19 Hooks。它专注于处理 Effect 周边的生命周期问题，包括订阅、定时器、任务取消、浏览器回退值，以及只暴露已提交数据的状态语义。

## 这个库优先解决什么

- **组合优先。** 每个 Hook 只解决一个生命周期问题，并能自然地与 React 内置 Hook 配合。
- **可预测的清理。** 依赖变化或组件卸载时，定时器、监听器、订阅和异步任务都会被释放。
- **服务端安全渲染。** 导入模块时不触碰浏览器 API；面向浏览器的 Hooks 提供明确的服务端快照。
- **直接导入。** 每个公开 Hook 都有显式 package export，整个包同时声明 `sideEffects: false`。
- **类型推断。** 泛型值、回调参数和事件映射可以贯穿公开 API，无需额外断言。

## 项目状态

Better Hooks 当前处于 **Preview（预览版）**。源码和文档已在 [GitHub](https://github.com/chenyu1ov3/better-hooks) 公开，npm 发布仍在准备中。在确认发布产物可用之前，文档不会提供未经验证的安装命令。

## 接下来阅读什么

先从[快速开始](/zh/docs/getting-started)了解客户端边界与导入约定，再通过 [Hooks 索引](/zh/hooks)按使用场景选择 API。在服务端渲染应用中使用浏览器 Hook 前，请先阅读 [SSR 与 RSC](/zh/docs/ssr-rsc)。

## 非目标

Better Hooks 是无样式的底层能力库。它不提供 UI 组件、请求缓存或状态容器，也不替代 React 的 `useTransition`、`useOptimistic` 和 `useActionState` 等 API。
