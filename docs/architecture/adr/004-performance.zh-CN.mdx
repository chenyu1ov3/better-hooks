# ADR 004 — 性能证据

## 状态

已采纳。

## 背景

缺少测量条件的包体积和竞品图表很快就会过期。即使单个 Hook 很小，也可能引入不必要的订阅或客户端 hydration。

## 决策

体积声明必须来自当前构建入口，并注明测量方式。官网可以展示零运行时依赖、显式 exports 和 `sideEffects: false` 等 manifest 事实，但不会编造竞品基准数据、下载量或覆盖率百分比。

只要所有权与清理规则保持清晰，运行时实现就会共享原生订阅；文档与示例也只在真正需要交互的位置进行 hydration。

## 影响

性能页面展示的数字可能比营销网站少，这是有意为之。证据应由构建工具更新；未经验证的数字宁可不展示，也不会用看似权威的占位数据代替。
