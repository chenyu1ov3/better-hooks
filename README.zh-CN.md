## 核心保证

- 面向 React 19 与严格 TypeScript
- 仅发布 ESM，提供显式 exports，并声明 `sideEffects: false`
- 除 React peer dependency 外没有运行时依赖
- 导入过程对 SSR 安全，Client Component 边界清晰
